# Workflow Test Site — NamaBayiIslami (miniature)

Purpose: practice the full publishing pipeline BEFORE the real build.

- GitHub repo -> Cloudflare Pages auto-deploy
- Multi-page structure identical in shape to the real site
- /artikel/ blog section (path, not subdomain)
- Programmatic per-name pages (/arti-nama/x)
- sitemap.xml + robots.txt

## Contents (what each part rehearses)
| Path | What it rehearses |
|---|---|
| / (index.html) | The finder tool: client-side JS filters over an inline JSON dataset |
| /rangkaian.html | The signature feature: name combination generator |
| /arti-nama/*.html (8 files) | Programmatic per-name pages - the SEO engine |
| /artikel/ | The blog: path-based, static HTML articles |
| /metodologi.html | Trust page |
| sitemap.xml, robots.txt | SEO plumbing from day 1 |

## How the real site differs
Same skeleton, real dataset (~600 verified names at launch in one JSON file),
real design, ad slots (post-AdSense), and hundreds more per-name pages -
generated by script, never hand-edited.
