Mengapa Situs Ini Hanyalah Folder Berisi File

Contoh artikel

Struktur folder situs ini menjadi struktur URL-nya: file artikel/struktur-situs-statis.html diakses di alamat /artikel/struktur-situs-statis.html. Itulah seluruh "sistem"-nya.

Menambah artikel baru berarti menambah satu file HTML ke folder artikel/ dan memperbarui daftar artikel serta sitemap. Di situs produksi, semua itu dilakukan oleh Taksha; kamu hanya meminta perubahannya.
