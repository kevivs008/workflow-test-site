Cara Kerja Deploy Otomatis: GitHub ke Cloudflare Pages

Contoh artikel

Setiap kali isi repositori GitHub berubah, Cloudflare Pages otomatis membangun versi baru situs dalam sekitar satu menit. Tidak ada yang perlu diunggah manual.

Langkahnya

  • Perubahan file disimpan (commit) ke repositori.
  • Cloudflare Pages mendeteksi perubahan itu.
  • Situs versi baru dibangun dan menggantikan yang lama.
  • Versi lama tetap tersimpan — bisa dikembalikan dengan satu klik.

Alamat URL tidak pernah berubah, jadi pencarian Google dan semua tautan lama tetap berfungsi.

Situs uji untuk latihan alur kerja (GitHub → Cloudflare Pages). Bukan situs produksi.
